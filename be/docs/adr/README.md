| 번호 | 결정 | 날짜 |
|---|---|---|
| [001](001-conditional-update-claim.md) | 이중 출금은 락 대신 회차 상태의 조건부 UPDATE로 막는다 | 2026-10-10 |
| [002](002-transfer-outside-transaction.md) | 이체 API는 DB 트랜잭션 밖에서 호출한다 | 2026-09-30 |
| [003](003-no-retry-reconcile.md) | 결과를 모르는 이체는 다시 보내지 않고 거래내역으로 확정한다 | 2026-10-10 |
| [004](004-due-date-lte.md) | 이체 대상은 기한 "당일"이 아니라 "오늘 이하"로 조회한다 | 2026-09-28 |
| [005](005-clause-pessimistic-lock.md) | 특약 순번은 계약 행 비관적 락으로 정한다 | 2026-03-25 |
| [006](006-schedule-index.md) | 이체 대상 조회 인덱스는 (status, due_dt) 순서로 건다 | 2026-09-28 |

날짜는 해당 결정이 코드에 들어간 커밋 기준입니다. 2026-09 이후 결정은 프로젝트 기간(2026.02~03)이 끝난 뒤 개선하면서 내린 것입니다.
